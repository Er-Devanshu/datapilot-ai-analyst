# DataPilot

`datapilot` is the core Python package for the DataPilot AI Analyst.

It contains the agent orchestration layer, analytics and evidence generation, data/schema inspection, SQL generation and execution, LLM integration, and visualization functionality required to process a business question into a grounded analytical response.
